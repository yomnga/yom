# 🎬 Aiman — AI-Powered TikTok Affiliate Video Studio (Web App)

เว็บแอปพลิเคชันครบวงจรสำหรับครีเอเตอร์ TikTok Affiliate — สร้างวิดีโอสินค้าด้วย AI, จัดการหลายบัญชี, โพสต์และตั้งเวลาอัตโนมัติ ในที่เดียว

## เริ่มใช้งาน

```bash
npm install
npm start
# เปิด http://localhost:3000
```

ต้องการ Node.js 18 ขึ้นไป · ข้อมูลทั้งหมดเก็บในโฟลเดอร์ `data/` (สร้างอัตโนมัติ)

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| 🎬 **สร้างวิดีโอ AI** | วิดีโอ 1 ฉาก (8 วิ) หรือ 2 ฉาก (16 วิ) พร้อมระบบ Storyboard ให้ฉากต่อเนื่องเป็นธรรมชาติ |
| ✨ **2 โหมด AI** | Credit-Based (GPT Image + Veo 3) และ Google Flow (Nano Banana + Veo ด้วย Gemini API key ของคุณเอง) สลับได้อิสระ |
| 🤖 **Workflow อัตโนมัติเต็มรูปแบบ** | คลิกเดียว: สุ่มสไตล์ → AI เขียน prompt → สร้างภาพสินค้า → สร้างวิดีโอ → เข้าคลัง ผลิตต่อเนื่องได้สูงสุด 20 คลิปต่อคำสั่ง |
| 🛒 **นำเข้าสินค้า Affiliate** | ดึงรายการสินค้าจากบัญชี TikTok (ผ่าน TikTok Shop Open API) หรือเพิ่มเองพร้อมลิงก์/คอมมิชชั่น |
| 📤 **โพสต์ & ตั้งเวลา** | โพสต์ทันทีหรือตั้งเวลา เลือกได้หลายบัญชีพร้อมกัน แนบลิงก์สินค้า ใส่เพลง และให้ AI เขียนแคปชั่น — ทำงานเบื้องหลังอัตโนมัติ |
| 👤 **คลังตัวละคร & สไตล์** | บันทึกตัวละคร AI และสไตล์วิดีโอไว้ใช้ซ้ำ เพื่อคงเอกลักษณ์แบรนด์ |
| 📊 **แดชบอร์ดสถิติ** | วิดีโอที่สร้าง/โพสต์ เครดิตที่ใช้ ค่าใช้จ่ายรายเดือน และกราฟผลผลิต 14 วัน |
| 💾 **สำรอง & ย้ายข้อมูล** | Export/Import ทั้ง workspace ในคลิกเดียว |
| 📖 **คู่มือในตัว** | คู่มือการใช้งานภาษาไทยครบทุกฟีเจอร์ |
| 👥 **หลายบัญชี** | หลายบัญชี TikTok + หลายบัญชี Google Flow ในแอปเดียว พร้อมระบบ License (1 License = 1 เครื่อง) |

## โหมดจำลอง (ไม่มี API key ก็ทดลองได้)

ถ้ายังไม่ได้ตั้งค่า API key ระบบจะสร้างสื่อจำลอง (placeholder) และจำลองการโพสต์ เพื่อให้เห็นและทดสอบ workflow ครบทุกขั้นตอนโดยไม่มีค่าใช้จ่าย เมื่อพร้อมใช้งานจริง ใส่ key ที่หน้า **ตั้งค่า**:

- **OpenAI API Key** — สร้างภาพสินค้าด้วย GPT Image (โหมด Credit)
- **Gemini API Key** — สร้างภาพด้วย Nano Banana (gemini-2.5-flash-image), วิดีโอด้วย Veo 3 และเขียนแคปชั่นด้วย Gemini

## สถาปัตยกรรม

```
server/
  index.js      — Express API + static hosting
  store.js      — JSON-file data store (data/)
  pipeline.js   — คิวงานผลิตวิดีโออัตโนมัติ (สุ่มสไตล์ → prompt → ภาพ → วิดีโอ)
  providers.js  — adapter เรียก OpenAI / Gemini (Nano Banana, Veo 3) + placeholder fallback
  tiktok.js     — adapter TikTok Content Posting API + จำลองสินค้า Affiliate
  scheduler.js  — โพสต์ตามตารางเวลา (ตรวจทุก 30 วินาที)
public/         — SPA frontend (ภาษาไทย, ไม่มี build step)
```

## ขอบเขตและนโยบาย

- การเชื่อมต่อ TikTok ออกแบบให้ใช้ **API ทางการเท่านั้น** (Login Kit OAuth, Content Posting API, TikTok Shop Open API) — ต้องลงทะเบียนแอปกับ TikTok for Developers และผูก access token ต่อบัญชี บัญชีที่ยังไม่ผูก token จะทำงานในโหมดจำลอง
- **ไม่มีฟีเจอร์ลบลายน้ำ**: ลายน้ำ/เครื่องหมายแสดงที่มาบนสื่อที่สร้างด้วย AI (เช่นของ Veo) เป็นข้อกำหนดด้านความโปร่งใสของผู้ให้บริการ การลบออกขัดต่อเงื่อนไขการใช้งาน จึงตัดออกจากขอบเขตของโปรแกรมนี้โดยตั้งใจ
